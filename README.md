# Jüpiter Reklam web sitesi

Statik site, GitHub Pages üzerinde yayınlanır. Alan adı: jupiterreklam.com (CNAME dosyası).

## Yayın öncesi doldurulacaklar
- Tüm sayfalarda `[Telefon]`, `+90XXXXXXXXXX`, `90XXXXXXXXXX` (WhatsApp), `[Atölye / ofis adresi]`
- `[X]` rakamları (deneyim, proje sayısı, garanti)
- `iletisim.html` içindeki `WEB3FORMS_ANAHTARI` (web3forms.com'dan info@jupiterreklam.com ile ücretsiz alınır)
- KVKK metnindeki `[Firma ticaret unvanı]`
- Proje ve atölye fotoğrafları (`.ph` yer tutucuları yerine `<img>`; WebP önerilir)
- Logo kesinleşince başlıktaki yazı logosu ve `assets/favicon.svg`
